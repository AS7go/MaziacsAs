============================================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ MAZIACSAS
============================================================

1. Разархивируйте файл MaziacsAs_Linux.tar.gz в любую удобную 
   для вас папку.

2. Откройте терминал и перейдите в директорию с игрой:
   cd /путь/к/папке/MaziacsAs/

   (Внутри этой папки вы должны увидеть файлы: 
   LICENSE.txt, папку _internal и файл MaziacsAs)

3. Дайте права на выполнение основному файлу игры:
   chmod +x MaziacsAs

4. Запустите игру командой:
   ./MaziacsAs

------------------------------------------------------------
СИСТЕМНЫЕ ТРЕБОВАНИЯ:
Игра протестирована и гарантированно работает на Ubuntu (64-битная версия). 
Сборка может работать на других дистрибутивах Linux, 
основанных на Debian, однако стабильность на других 
семействах (Arch, Fedora и др.) не проверялась.

ВАЖНО:
Не перемещайте исполняемый файл MaziacsAs отдельно от 
папки _internal. Для корректной работы игры все файлы 
должны находиться в одной директории.
============================================================
